Automated Seaweed Harvester

A remotely-operated surface vehicle for harvesting farmed seaweed.

VehicleMarine

Farmed seaweed grows on long lines suspended below the surface, and harvesting it is slow, manual work done from boats. This is a remotely-operated vehicle built to do that job — run the line, cut and collect, without a crew aboard.
